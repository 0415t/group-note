# GroupNote

GroupNoteは、身近なグループやコミュニティ内での情報共有・ナレッジ蓄積をスムーズに行うための、拡張性に優れた共有メモアプリケーションです。

1dayインターンでの課題に対し、AI（v0）を活用した高速プロトタイピングにより1日でMVP（最小限のプロダクト）を構築。その後、ドメインモデルの整理や状態管理の最適化を行い、実用的なアプリへとブラッシュアップしました。

---

## 💡 開発の背景とアプローチ

### 1. 課題感とアイデア
友人から「飲み会を開いてほしい」と頼まれた際、よくイベントを主催する別の友人に相談したり、「大学の近くに新しい店ができたけどどう？」と情報を聞き合ったりする機会がありました。
同じ生活圏・コミュニティにいるグループ間では日常的に様々な情報共有が発生しますが、チャットツールでは流れてしまい、既存ツールでは柔軟な入力が難しいという課題を感じていました。

### 2. 1dayでの高速プロトタイピング（v0の活用）
「飲み会の店選びから日常の共有まで、どんな内容でもメモできる拡張性」をテーマに設定。1日という限られた時間の中でアイデアを素早く形にするため、**v0（AI UI生成ツール）** を活用して画面骨格とUIコンポーネントを一気に生成し、即座にプロトタイプを可視化・検証しました。

### 3. 追加開発とブラッシュアップ
プロトタイプ構築後、コンポーネント構造の最適化、ドメイン型定義（`User`, `Group`, `Memo`, `Template` 等）の厳密化、画面遷移を制御するカスタムStore（状態管理）の実装を行い、拡張性と保守性を備えたコードへ改良しました。
